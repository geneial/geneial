Representation and operators

Each gene is a compass direction. A wall blocks a move; it never teleports an explorer. Selection keeps promising prefixes, crossover exchanges tails, and mutations explore legal corridors. Loop-erasure repair removes wasted moves; after finding an exit, evolution keeps shortening the route.

Fitness

A reverse breadth-first distance field measures corridor distance to the exit, not straight-line distance through walls. It guides the score, but never supplies a route to an agent. This is an informed search, not a claim to beat a maze solver.

Browser and native versions

This playground runs an actual JavaScript genetic algorithm locally. The matching native GeneiAL C++ demo exports SVG, CSV, and a standalone replay. Both use the same seeded maze generator; their evolutionary histories differ.
