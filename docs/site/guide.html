THE DEVELOPER GUIDE / 0.3

Build. Mutate. Repeat.

GeneiAL maximizes a fitness function over a population of chromosomes. Operators define who reproduces, how genomes recombine, which mutations occur, and when the search stops. For minimization, return the negative cost.

01 / Get a working build

Requirements: a C++20 compiler and standard library with std::span and std::jthread, CMake 3.21+, and Ninja. Use GCC/libstdc++ 12+, Clang with libstdc++ 12+, LLVM/libc++ 20+, or a current Xcode 26 toolchain. CMake checks the required library features. Boost.Test is only needed when building tests. Windows/MSVC is not currently in the validation matrix. 

# macOS
brew install cmake ninja boost
# Ubuntu 24.04
sudo apt-get install build-essential cmake ninja-build libboost-test-dev

git clone https://github.com/geneial/geneial.git
cd geneial
cmake --preset release
cmake --build --preset release --parallel
ctest --preset release --output-on-failure

Presets: release, debug, sanitized (ASan + UBSan), and library (no Boost, tests, or examples). Builds stay under output/. The legacy cmake -S src -B output/legacy entry point remains supported.

02 / Run the experiments

mkdir -p output/art
./output/release/src/demo/voronoi_art \
  --seed 42 --threads 4 --shapes 24 --generations 6000 \
  --output output/art/cells
./output/release/src/demo/triangle_art \
  --seed 42 --threads 4 --shapes 50 --generations 12000 \
  --output output/art/triangles

# Use your own target (P3/P6 PPM, 8-bit samples)
./output/release/src/demo/triangle_art \
  --input your-image.ppm --output output/art/custom

Open the exported .html directly: it contains its own artwork, replay controls, and fitness chart. The .svg is editable vector artwork; .csv contains generation/fitness history. The two portrait demos also export the exact fitness raster as .ppm.

Executable Genome / objective Special option
voronoi_art Colored sites / RGB mean squared error --shapes: initial sites; grows to 128
triangle_art Layered triangles / RGB mean squared error --shapes: fixed triangle count
star_tour 48-star permutation / closed route length --seed

pixel_art Palette indices / total RGB squared error --generations

All accept --help, --seed, --population, --generations, and --output. Output parent directories must exist. Longer art runs generally help, but convergence is heuristic and not guaranteed.

03 / Understand the art

Chromatic cells

Each site stores x/y coordinates and RGB color. Each fitness pixel takes the color of its nearest site. Local mutations move sites or adjust color. Duplication adds material that can diverge; deletion lets neighboring cells fill the gap. The genome varies between 4 and 128 sites. Half-plane clipping creates the final vector cells without SciPy or a graphics library.

EvoLisa

Each triangle has six coordinate genes, RGB, and alpha. Fifty layers by default are composited in order over a dark background. Small mutations alter geometry and paint, occasional swaps alter layer order, and shape-block crossover mixes parents. CPU workers evaluate independent candidate rasters in parallel.

Both initialize colors by sampling the target at site positions or triangle centroids; initial geometry is random. Fitness uses a target downsampled to at most 40 × 60, squared error in encoded RGB space, and non-antialiased pixel-center sampling. SVG rendering is resolution-independent and browser-antialiased, so the PPM—not a screenshot—is the exact fitness image. This is an educational CPU implementation inspired by the linked work, not a performance or reproduction claim.

04 / Use it in your project

cmake --preset library
cmake --build --preset library
cmake --install output/library --prefix "$HOME/.local"
find_package(geneial 0.3 CONFIG REQUIRED)
target_link_libraries(your_program PRIVATE geneial::geneial)
# Or geneial::geneial_shared for the shared library.

Use FunctionFitnessEvaluator<Value, Score> for a C++ callable accepting std::span<const Value>. Factory settings are owned by the factory and may outlive the builder. See the compiled consumer example, architecture guide, and complete showcase sources.

05 / Reproducibility and safety

Return finite fitness scores. Populations reject null candidates and NaN/infinity, resolve hash collisions with full genome equality, and stage whole-population replacement before changing their indexes. containsChromosome() checks genome membership; a hash alone is not an identity. Populations are manager-bound and cannot be copied.

Stateful stopping criteria sample once per observed generation. They reset when switching managers or rewinding population age; explicitly call reset() on each stateful criterion for same-generation restarts. Fix-point detection requires at least two observations, and trailing stop measures absolute drawdown from the best observed fitness. Keep genomes retained by population-unchanged stopping immutable until reset, even after removal from the current population.

Call Random::initialize(seed) on the thread making stochastic decisions. The engine is thread-local. Draw sequences repeat within the same build and standard library, not necessarily across platforms. Art workers never draw random numbers, and serial/parallel runs are checked for identical fitness histories.

A chromosome’s cached fitness is lazy. Do not mutate a chromosome already indexed in a population, retain a mutable genome reference across evaluations, or evaluate the same uncached chromosome concurrently. Parallel evaluators must be reentrant, avoid shared mutable state, and not recursively wait on their own worker pool.

Worker exceptions are rethrown by waitForTasks() after all submitted work drains. Destruction drains tasks but cannot report unobserved task exceptions: explicitly wait. Pool shutdown/join is an owner-thread operation. Invalid ranges, impossible crossover/mutation dimensions, and exhausted population replenishment throw standard exceptions.

06 / Build this website

cmake --build --preset release --target website
python3 -m http.server 8765 --bind 127.0.0.1 \
  --directory output/release/site
# Browse http://127.0.0.1:8765

The target runs all five real searches and assembles a dependency-free static gallery. GitHub Pages automation builds the gallery plus Doxygen API documentation. The repository administrator must select GitHub Actions as the Pages source. No deployment happens merely by building or committing locally.
